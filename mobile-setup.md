# QuantumTrade AI Mobile App Setup Guide

## Quick Start - Install on Your Phone

### Option 1: Expo Go (Fastest - 5 minutes)

1. **Download Expo Go** on your phone:
   - iOS: App Store → Search "Expo Go"
   - Android: Google Play → Search "Expo Go"

2. **Install dependencies** on your computer:
   ```bash
   npm install -g expo-cli
   npm install expo react-native react-native-chart-kit react-native-svg
   ```

3. **Start the app**:
   ```bash
   npx expo start
   ```

4. **Scan QR code** with Expo Go app to run on your phone

### Option 2: Build Native App (Production Ready)

1. **Create Expo account**: https://expo.dev/signup

2. **Build for your platform**:
   ```bash
   # For Android APK
   npx expo build:android

   # For iOS (requires Apple Developer account)
   npx expo build:ios
   ```

3. **Download and install** the generated file on your phone
