### Option 1: Direct APK Download (Android)
1. Open your phone browser and visit: `https://expo.dev/artifacts/eas/quantumtrade-ai.apk`
2. Download the APK file
3. Enable "Install from Unknown Sources" in Settings
4. Install the downloaded APK

### Option 2: Expo Go (iOS & Android)
1. Download "Expo Go" from App Store or Google Play
2. Scan this QR code with Expo Go:

## Build Your Own Version

### Prerequisites
```bash
npm install -g expo-cli
```

### Build Commands
```bash
# Clone mobile app
cp MobileApp.tsx App.js
cp package.mobile.json package.json
cp mobile-config.json app.json

# Install dependencies
npm install

# Start development server
expo start

# Build for Android
expo build:android

# Build for iOS
expo build:ios
```
